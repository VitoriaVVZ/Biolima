Passo a passo de como criar um HTML

  1. Passo 1: Entre em um editor de código. (EX: VS-Code)
  2. Passo 2: Crie uma pasta e um arquivo em branco
  3. Passo 3: Digite uma Tag de declaração "!DOCTYPE html" para definir que é um documento HTML

    4. Bonus: Caso voce seja preguiçoso e nao queira fazer tudo manualmente. Digite "!" e aperte ENTER

  4. Passo 4: Abra a estrutura com a Tag "html" e feche com "/html"
  5. Passo 5: Adicione abaixo a Tag head e dentro dela coloque "title'titulo da sua pagina'/title" para dar um titulo a sua pagina
  6. Passo 6: Abra a Tag body logo abaixo de head. Ela sera aonde voce ira colocar todo o conteudo da sua página
  7. Passo 7: Adicione um titulo principal a sua pagina utilizando "h1"
  8. Passo 8: Insira um parágrafo de texto com p
  9. Passo 9: Feche o corpo do seu codigo com /body
  10. Passo 10: Salve o Arquivo contendo .html no final. (EX: index.html) e abra no seu navegador

Checklist de Atividades

  1. Revisar se o código funciona sem erros no console
  2. Verificar se o nome do arquivo segue o padrão exigido
  3. Validar a indentação e organização do código (Clean Code)
  4. Remover qualquer comentario no codigo
  5. Enviar o codigo a alguem para verificar se acha erro
  6. Verificar links quebrados ou caminhos de imagens incorretos
  7. Garantir que o arquivo foi salvo antes de compactar ou enviar
  8. Conferir se todos os requisitos da atividade foram atendidos
  9. Fazer o commit e push para o repositório (se necessário)
  10. Anexar todos os arquivos necessários (HTML, CSS, Imagens)
